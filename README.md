# CANSAT 
## General Description
This is the code used for a telemetry scholar project.
Some modules for the devices used came from external libraries, and i had the aim of edit these libraries to get better understanding od the MC
The project was build with a MC *PIC18F4550*, within the MPLAB IDE.
## Aim of the project
The project was intended for the development of a telemetry system, the CANSAT type is a small and compact project for achieving this.
